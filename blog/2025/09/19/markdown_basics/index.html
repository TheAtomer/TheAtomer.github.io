Markdown基础语法

什么是 Markdown?

Markdown 是一种轻量级的标记语言，设计用于让普通文本具有丰富的格式表现，同时保留文本内容的易读性和易写性。它通过简单直观的标记符号来实现文档的格式化，广泛应用于技术文档、博客文章、电子邮件、笔记和协作文档的编写。

为什么选择 Markdown?

  1. 简单直观：语法非常容易掌握，只需熟悉常见标记符号即可快速上手。
  2. 跨平台支持：支持多种平台和工具，如 GitHub、Notion、VS Code、Jupyter Notebook 等。
  3. 多格式输出：文档可以转换为 HTML、PDF、Word 等多种格式，适应不同需求。
  4. 专注创作：无需复杂的排版工具，专注内容本身，提高写作效率。

Markdown 语法详解

以下是 Markdown 的常用语法及其详细示例：

1. 标题

Markdown 使用 # 符号来表示标题，支持六级标题，# 的数量代表标题的级别。

2. 段落与换行

普通的文本直接书写即可。若需要换行，在行尾添加两个空格。

3. 强调

Markdown 支持斜体和加粗，以及两者的组合。

4. 列表

Markdown 支持无序列表和有序列表。

无序列表

使用 -、* 或 + 作为标记符，子列表可通过缩进实现。

有序列表

使用数字加点 .，数字顺序可以不连续，最终会按顺序渲染，子列表同样可通过缩进实现。

5. 链接

可添加基础超链接，也可添加标题提示（鼠标悬停时显示）。

6. 图片

添加图片与链接类似，只需在前面加一个 !，图片可以是本地图片或网络图片（图床链接）。

7. 引用

引用使用 > 进行标记，支持嵌套引用（多个 > 叠加）。

8. 代码块

分为行内代码和多行代码块，多行代码块支持指定编程语言以实现语法高亮。

行内代码

用反引号 ` 包裹代码内容。

多行代码块

用三个反引号包裹代码内容，在开头反引号后指定编程语言。

9. 表格

使用 | 分隔列，- 分隔表头与表格内容（- 数量至少1个，可通过 : 调整列对齐方式，默认左对齐）。

10. 分隔线

使用三个或更多的 -、* 或 _ 创建分隔线，符号之间可加空格，不可与其他内容同行。
